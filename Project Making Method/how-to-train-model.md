# SLI (Sign Language Interpreter)

## What is this? And how it works?
This project uses MediaPipe to get data. Mediapipe is developed by google which draw landmarks on pictures which help to extract data. This data is used to train various machine learning models.

In this project we are using a **Random Forest** model to recognize Sign Language (ASL). It also includes **real-time sign recognition** using your webcam.
